# 喋って本キット　新規タブ（Chrome 拡張機能）

新しいタブを開くと、喋って本キット 子育て版が出ます。右上のボタンで不登校版・結婚の流儀（男性専用）に切り替えられます。
このページは通信しません。

## 入れ方（1回だけ）

1. この `chrome-newtab` フォルダを、消さない場所に置く（例：ドキュメントの中）。
2. Chrome のアドレスバーに `chrome://extensions` と打って開く。
3. 右上の「デベロッパー モード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押して、`chrome-newtab` フォルダを選ぶ。
5. 新しいタブを開く。「このページを変更しましたか？」と出たら「変更を保持」を押す。

## 気をつけること

- Google のいつもの新規タブ（検索窓とショートカット）は出なくなります。検索はアドレスバーに打ってください。
  元に戻すときは `chrome://extensions` でこの拡張機能をオフにします。
- フォルダを動かしたり消したりすると、拡張機能が動かなくなります。そのときは手順 4 からやり直してください。
- 書きかけの欄やチェックは、ファイルで開いたキット（固定タブ）とは別に記憶されます。
  続きを引き継ぐなら、新規タブ側でも「保存先（Obsidian vault）を選ぶ」から同じ jigyo-vault を選んでください。vault の中身を読み込みます。
- 新規タブを何枚開いても大丈夫です。別のタブで進めた分は、そのタブに戻ったときに取り込みます。

## キットを直したとき

キット本体（`kosodate-kindle-kit.html` / `futoko-kindle-kit.html` / `kekkon-kindle-kit.html`）を直したら、
`python3 build-newtab.py` を実行してから、`chrome://extensions` でこの拡張機能の「↻」（再読み込み）を押してください。
